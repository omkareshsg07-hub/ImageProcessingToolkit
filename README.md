
# Image Processing Toolkit

A simple image-processing toolkit developed using
Python and OpenCV.

## Features
- Grayscale conversion
- Gaussian blur
- Canny edge detection
- Binary thresholding
- Contrast enhancement using CLAHE

## Technologies
- Python
- OpenCV

## Installation

```bash
pip install opencv-python
```

## Usage

```bash
python image_toolkit.py photo.jpg --operation edges
```

## Supported Operations
- grayscale
- blur
- edges
- threshold
- enhance
